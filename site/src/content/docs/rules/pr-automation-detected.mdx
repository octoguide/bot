Pull requests labeled as automated (e.g. `automation-signal`) or AI-generated (e.g. `ai slop`) indicate contributions that were not meaningfully authored by a human.
These contributions are often low-quality, miss project context, and create unnecessary review burden for maintainers.

When a matching label is detected on an open PR, OctoGuide will post a comment explaining the closure and then close the pull request.

## Matched Labels

At this time, the following label names are matched case-insensitively:

- `automation-signal` or `automation signal`
- `ai-slop` or `ai slop`

## Running on Labels

Adding a label to a pull request fires the `labeled` event.
OctoGuide's [default workflow](/get-started#installation) doesn't run on `labeled`, so this rule only checks pull requests when they're opened or edited.
To check pull requests as soon as a matching label is added, add `labeled` to the workflow's `pull_request_target` types:

<Code
	code={getStartedLabeled}
	ins="labeled, "
	lang="yml"
	title=".github/workflows/octoguide.yml"
/>
